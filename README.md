# Yatube API 🚀

**Yatube API** — это бэкенд-часть социальной сети, имитирующая сервис публикации постов (аналог Instagram). Проект позволяет пользователям публиковать записи, подписываться на авторов, оставлять комментарии и объединяться в тематические группы.

## 🛠 Технологии

* **Python 3.9+**
* **Django 3.2+**
* **Django REST Framework**
* **JWT Authentication** (SimpleJWT)
* **Djoser** (управление пользователями)
* **SQLite3** (база данных для разработки)

## 🚀 Как запустить проект

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/Venius24/api_final_yatube
cd api_final_yatube

```


2. **Cоздайте и активируйте виртуальное окружение:**
```bash
python -3.12 -m venv venv #3.12 требуется для корректной работы
source venv/Scripts/activate  # Для Windows
source venv/bin/activate       # Для Linux/macOS

```


3. **Установите зависимости:**
```bash
pip install -r requirements.txt

```


4. **Выполните миграции:**
```bash
python manage.py migrate

```


5. **Запустите сервер:**
```bash
python manage.py runserver

```

*Когда вы запустите проект, по адресу  `http://127.0.0.1:8000/redoc/` будет доступна документация для API Yatube*

## 🔑 Аутентификация и использование

В проекте используется аутентификация с помощью **JWT-токенов**.

1. **Регистрация пользователя:**
Отправьте `POST`-запрос на `http://127.0.0.1:8000/api/v1/users/` с полями `username` и `password`.
2. **Получение токена:**
Отправьте `POST`-запрос на `http://127.0.0.1:8000/api/v1/jwt/create/`. В ответ придет `access` токен.
3. **Работа с API:**
В каждом запросе (кроме регистрации) передавайте токен в заголовке:
`Authorization: Bearer <ваш_токен>`

## 📖 Примеры эндпоинтов

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `GET` | `/api/v1/posts/` | Получить список всех постов |
| `POST` | `/api/v1/posts/` | Создать новый пост (нужен токен) |
| `GET` | `/api/v1/groups/` | Получить список всех групп |
| `GET` | `/api/v1/follow/` | Список подписок текущего пользователя |
| `POST` | `/api/v1/follow/` | Подписаться на автора |

### Пример запроса на создание поста:

**POST** `/api/v1/posts/`

```json
{
    "text": "Мой первый пост в Yatube!",
    "group": 1
}

```
